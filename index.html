FAQ

Questions fréquentes

Il faut savoir coder pour l'utiliser ?

Non. Le code est prêt à lancer. Il suffit d'avoir Python installé et de remplir quelques variables (token Discord, IDs de salons). Le README explique tout étape par étape.

Je peux faire payer mes propres abonnés avec ce bot ?

Oui, c'est exactement l'idée. Le système de rôles Premium est déjà intégré — tu gères qui voit quoi depuis le panel admin Discord.

Le bot fonctionne 24h/24 ?

Oui, à condition de le laisser tourner sur un serveur ou un PC allumé en permanence. On peut te conseiller des hébergeurs abordables (VPS à 5€/mois).

Comment je reçois le code après paiement ?

Tu rejoins le Discord, tu envoies la preuve de paiement, et tu reçois les fichiers dans les minutes qui suivent.

Je peux ajouter mes propres marques ?

Oui, c'est entièrement configurable. Tu modifies simplement les listes dans le fichier scraper pour ajouter ou retirer des marques.
